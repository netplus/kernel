# Linux Kernel 5.10 系统学习

这个仓库用于系统学习 Linux kernel 5.10。内容按照汇编、调度、时钟、内存和网络等主题分别整理。学习某个主题时，可以沿对应目录逐章阅读；分析一个完整的内核执行过程时，可以通过 `integrated-paths/` 把多个子系统串联起来。

## 课程目录

```text
kernel/
├── assembly/           x86-64 汇编、ABI、ELF 和内核入口
├── scheduler/          调度、抢占、唤醒、负载均衡和上下文切换
├── timekeeping/        时钟源、时钟事件、tick、timer、hrtimer 和 NO_HZ
├── memory/             页表、memblock、伙伴系统、SLUB、缺页、回收和 NUMA
├── network/            Linux 5.10 网络协议栈
└── integrated-paths/   跨子系统执行过程和综合案例
```

各主题目录将逐步采用下面的结构：

```text
README.md               课程大纲和学习顺序
docs/                   分章节教程
labs/                   实验、脚本和调试记录
source-paths/           Linux 5.10 源码位置、调用路径和关键数据结构
```

Git 不保存空目录。因此，在某个主题尚未开始编写具体章节时，目录中可能只有 `README.md`；后续会随着课程推进逐步增加 `docs/`、`labs/` 和 `source-paths/`。

## 各主题之间的关系

汇编、调度、时钟、内存和网络虽然分开整理，但它们在内核中经常共同工作。

- 汇编知识用于理解寄存器、栈、系统调用、异常入口和上下文切换；
- 调度器需要时钟提供运行时间，并在任务阻塞、唤醒或需要抢占时选择下一个任务；
- 内存管理为进程地址空间、内核栈、页表、网络报文和 DMA 缓冲区提供存储；
- 网络收包过程会经过中断、NAPI、softirq、内存分配、协议处理和任务唤醒；
- 一个实际故障通常会同时涉及多个子系统。

因此，课程提供两种学习方式。

### 按主题逐步学习

可以分别学习：

```text
assembly
scheduler
timekeeping
memory
network
```

这种方式适合先建立每个子系统的基本概念、主要数据结构和源码框架。

### 按完整执行过程学习

也可以从一个实际过程出发，沿调用路径逐步分析。例如：

```text
系统调用：
用户态 → syscall 入口 → 内核函数 → 返回用户态

调度切换：
时钟中断 → scheduler_tick → 设置调度标志 → schedule → switch_to

缺页异常：
内存访问 → #PF → 缺页入口 → VMA 检查 → 建立页表或发送信号

网络收包：
网卡 IRQ → NAPI → softirq → skb → IP/TCP → socket → 唤醒进程
```

这类跨子系统内容统一放在 [`integrated-paths/`](integrated-paths/) 中。

## 章节的讲解方式

每一章尽量按照下面的顺序展开：

```text
问题背景：说明本章要解决什么问题。
基本原理：先建立直观、完整的工作模型。
源码位置：定位 Linux 5.10 中的入口、数据结构和主要函数。
调用过程：沿实际执行路径分析关键步骤。
实验验证：使用代码、命令、GDB、objdump、ftrace、perf 或 crash 验证结论。
补充内容：说明性能、并发、安全、边界条件和版本差异。
相关知识：指出与其他子系统的联系，但不打断当前主线。
```

首次学习时，可以先掌握问题背景、基本原理和主要调用过程；熟悉主线后，再继续阅读源码细节和补充内容。

## 推荐学习顺序

### 第一阶段：机器执行基础

先学习 [`assembly/`](assembly/) 中的寄存器、取址、标志位、算术、控制流、栈和函数调用约定。

这些内容是阅读系统调用入口、异常入口和上下文切换代码的基础。

### 第二阶段：内核运行基础

接着学习：

- [`scheduler/`](scheduler/)：任务如何运行、阻塞、唤醒、抢占和迁移；
- [`timekeeping/`](timekeeping/)：内核如何读取时间、安排定时事件并驱动周期性工作；
- [`memory/`](memory/)：虚拟地址如何映射，物理页和内核对象如何分配、使用和回收。

这三个主题可以交叉学习，因为调度、时钟和内存管理之间联系紧密。

### 第三阶段：网络协议栈

进入 [`network/`](network/) 后，将前面学习的中断、softirq、内存、定时器和调度知识带入实际收发包路径。

### 第四阶段：完整执行过程

最后通过 [`integrated-paths/`](integrated-paths/) 分析系统调用、任务切换、缺页异常、网络收发和内核崩溃等综合专题。

## 源码和实验环境

```text
内核版本：Linux kernel 5.10
主要架构：x86-64
汇编器：GNU assembler
主要汇编语法：AT&T
用户态 ABI：System V AMD64 ABI
```

涉及其他内核版本时，课程会先以 Linux 5.10 说明基本机制，再补充不同版本之间的主要变化。
